GOLD SCALPER AI - OWMarkets XAUUSD update

معلومات العقد التي زودنا بها المستخدم:
- Contract size = 100 أونصة لكل 1.00 lot
- Min lot = 0.01
- Volume step = 0.01
- Tick size = 0.01
- الحساب USD

الحساب النظري:
0.01 lot = 100 * 0.01 = 1 أونصة.
قيمة tick عند 0.01 lot = 1 أونصة * 0.01 دولار = 0.01 دولار.
حركة 1.00 دولار في الذهب تعطي تقريباً 1.00 دولار ربح/خسارة قبل التكاليف.

ملاحظة: السبريد والعمولة والسواب وقيمة التيك النهائية يجب التحقق منها من مواصفات الرمز داخل MT5 لدى OWMarkets. الرافعة تؤثر في الهامش لا في الربح والخسارة.
اختيار 1-5 دقائق/5-30 دقيقة واجهة اختيار؛ مصدر السعر الحالي لا يضمن بيانات شموع دقيقة ولا يمثل بث MT5 مباشراً. لا تستخدم الإشارات كضمان أو كتنفيذ آلي.
